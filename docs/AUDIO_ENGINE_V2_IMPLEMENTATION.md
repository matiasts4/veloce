# Audio Engine Upgrade (V2) - VAD & Diarization

This document details the implementation of the new Audio Engine features: Neural VAD, Real-time Streaming, and Speaker Diarization.

## 1. Advanced VAD (Voice Activity Detection)
Replaced the simple RMS energy threshold with **Silero VAD**, a pre-trained neural network for high-precision speech detection.

*   **Implementation:** `VADDetector` class in `audio_engine.py`.
*   **Logic:** Uses `snakers4/silero-vad` from Torch Hub.
*   **Performance:** Drastically reduces hallucinations during silence and background noise.
*   **Fallback:** Gracefully degrades to energy-based detection if the model fails to load.

## 2. Real-time Streaming Architecture
Implemented a `StreamProcessor` class to handle audio buffering and partial transcription.

*   **Workflow:**
    1.  Audio chunks are processed by VAD.
    2.  Active speech is buffered.
    3.  **Partial Results:** Every ~0.8s, the active buffer is sent to a background thread for partial transcription, providing immediate feedback to the user.
    4.  **Finalization:** When silence (>600ms) is detected, the segment is finalized and a full transcription is performed.

## 3. Speaker Diarization
Added speaker identification ("Speaker 1", "Speaker 2") using **SpeechBrain's ECAPA-VoxCeleb**.

*   **Implementation:** `DiarizationManager` class.
*   **Model:** `speechbrain/spkrec-ecapa-voxceleb` (automatically downloaded to `python/models/`).
*   **Mechanism:**
    *   Extracts a 192-dimensional embedding vector from each finalized audio segment.
    *   Compares the embedding against a bank of known speakers using Cosine Similarity.
    *   **Threshold:** >0.55 similarity assigns the existing Speaker ID. Otherwise, a new ID is created.
*   **Optimization:** Diarization only runs on *final* segments to save resources. Loading is asynchronous to prevent app startup lag.

## 4. Dependencies
New Python packages added to `requirements.txt`:
*   `onnxruntime`: For efficient VAD execution.
*   `scikit-learn`: For potential future clustering (currently using direct similarity).
*   `speechbrain`: For speaker embedding extraction.
*   `transformers`: Required by SpeechBrain.

## 5. Usage
No manual configuration required. The system automatically initializes these components on startup.
*   **VAD:** Active by default.
*   **Diarization:** Active by default (lazy-loaded in background).
*   **Streaming:** Active by default.

## 6. Commands (Updated)

The engine accepts commands via `stdin`.

### DOWNLOAD (JSON Payload)
Initiates a model download.

**Format:**
```json
DOWNLOAD {"model": "large-v3-turbo", "dir": "C:/Models"}
```

- `model`: Model identifier (e.g., `tiny`, `base`).
- `dir` (Optional): Target directory for download.
